Privacy Policy

ytpl is a local command-line client for YouTube API Services. This policy explains the data it uses to run the commands you choose.

What ytpl accesses

With your Google authorization, ytpl reads your YouTube channel ID, name, and available handle to identify the active channel. Playlist commands use playlist IDs, titles, descriptions, privacy settings, and the video and item information needed to display, export, or update a playlist.

Where the data goes

ytpl exchanges OAuth credentials with Google and sends playlist requests directly to the YouTube Data API. If you request a playlist change, Google receives the information needed for that change, such as video IDs, playlist titles, or item positions. The app developer receives no copy of your credentials or playlist data from the CLI.

The CLI performs its work locally, with no advertising or analytics. Google handles authorization and YouTube API traffic under its own policy. Google Privacy Policy

Local storage

ytpl keeps its OAuth configuration, authorization tokens, and local playlist cache in its state directory. The default is .state in the directory where you run ytpl. You can choose another location with --state-dir or YTPL_STATE_DIR. Exports and optional migration input and output files are stored at the local paths you choose.

GitHub hosts these documentation pages and processes site visits under its own policy. GitHub Privacy Statement

Revoke access and delete local data

  1. Remove ytpl access in your Google Account permissions.
  2. Run ytpl auth logout to remove the stored OAuth token.
  3. Delete the local state directory and any exported files you no longer need. Manage playlists stored on YouTube in your YouTube account.
