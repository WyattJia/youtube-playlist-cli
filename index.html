ytpl

Manage YouTube and YouTube Music playlists from your terminal.

Playlist commands

List and export playlists, add or remove videos, and change playlist order. ytpl runs on your computer and uses YouTube Data API v3 to read and update playlists.

Google authorization

A Google Desktop OAuth client lets ytpl access your YouTube channel. OAuth is required for private playlists and for changes. You can also use an API key to read public playlists.
